Estrutura dos Módulos

1. Ecossistema Pills (Barramento Sem Fios & Variantes) 20 Pilhas

Componentes de transmissão sem fios (PillHub), concentradores verticais de parâmetros, cofre de variantes com conectores estilo Galapagos e caches inteligentes para otimização acústica e paramétrica.

2. Manipulação Avançada de Árvores de Dados (Data Trees) 19 Pilhas

Conjunto profissional de ferramentas para reestruturação topológica, filtragem por caminhos, alinhamento de árvores, particionamento e entrelaçamento dinâmico de dados.

3. Estatística, Probabilidade e Distribuições 20 Pilhas

Módulos de estatística descritiva, detecção de outliers (IQR/MAD), correlações, entropia de informação e distribuições contínuas/discretas (Beta, Binomial, Qui-Quadrado, Weibull, etc.).

4. Automação, Estados e Processos Iterativos 9 Pilhas

Ferramentas para criação de loops, acumuladores circulares (com exportação JSON), travas lógicas (State Latch) e monitoramento de convergência.

5. Avaliação de Modelos e Metas de Projeto 7 Pilhas

Métricas de validação de erro (R², RMSE, MAE), cálculo de desvios relativos de metas de projeto e análise de dispersão geométrica.

6. Visualização Gráfica no Canvas 12 Pilhas

Renderizadores de gráficos analíticos 2D diretamente no Canvas do Grasshopper (linhas, dispersão X/Y e mapas de calor espaciais).

7. Matemática em Massa e Agrupamento 3 Pilhas

Operações matemáticas de alto desempenho vetorizadas em árvores, somas condicionais (SumIf) e agrupamento rápido por similaridade.

8. Álgebra Linear e Matrizes 5 Pilhas

Construção e inspeção de matrizes, multiplicação, inversa, determinante, sistemas lineares e autovalores.

9. Importação e Exportação de Dados (I/O) 6 Pilhas

Leitores e exportadores de dados tabulares (CSV, texto delimitado e planilhas multi-abas) e serialização de DataTrees sem perda (JSON tipado, CSV longo, binário Glaux, .pilldata) com hash de identidade.

10. Dados & Persistência (Store Local) 7 Pilhas

Store local .glauxdb com revisões, consultas estruturadas, inspeção de esquema, validação de dados e sincronização sem laços entre o Grasshopper e o store.

11. Project Vault & Proveniência 5 Pilhas

Snapshots de parâmetros, controles, entradas e resultados; histórico, comparação, restauração e registro de experimentos: com quais parâmetros cada resultado foi produzido.

12. Desempenho & Diagnóstico 1 Pilha

Profiler de execução sem instrumentação: tempo por componente × tempo da solução, percentis, memória, cache e custo do próprio profiler, com série histórica no store.

13. Dashboard & Controles 2 Pilhas

Painéis interativos no canvas que reúnem controles (slider, toggle, botão, lista) e indicadores (texto, número, progresso, mini gráfico) ligados ao PillHub, com entrega ao Grasshopper sem recomputações em cascata e estado integrado a presets e snapshots.

1. Ecossistema Pills (Barramento Sem Fios & Variantes)

Componentes de transmissão sem fios (PillHub), concentradores verticais de parâmetros, cofre de variantes com conectores estilo Galapagos e caches inteligentes para otimização acústica e paramétrica. (Total: 20 componentes)

Pill Bundle Pack (Parameter Hub) Pills
PillPack
Empacota múltiplos parâmetros, listas ou árvores nomeadas em um único pacote estruturado (PillBundle / Hub Central). Permite puxar automaticamente canais por nome de grupo/categoria (ex: 'ACU', 'GEO', 'ALL') ou empacotar valores manuais. Reduz a fiação complexa a uma única linha de transmissão e suporta exportação JSON.
Direção Nome (Sigla) Tipo Descrição
INPUT Keys (K) Text Lista de chaves de parâmetros (ex: 'ACU_T60_Alvo [s]') OU nomes de grupos/categorias (ex: 'ACU', 'GEO', 'MAT', 'ALL'). Se for um grupo, todas as variáveis ativas dessa categoria são automaticamente colhidas do barramento PillHub.
INPUT Values (V) Generic Valores manuais OPCIONAIS. DEIXE DESCONECTADO para colher automaticamente dos Transmitters do Canvas (via Wires ⚡ e PillHub). Conecte aqui apenas se quiser forçar valores manuais sem transmissores.
INPUT Namespace (NS) Text Namespace ou prefixo de escopo opcional (ex: 'SALA_01' ou 'CONFIG').
INPUT Wires (⚡) Generic Cabos físicos ocultos automáticos (Wire Display: Hidden) dos Transmitters correspondentes para sincronização no Wallacei.
OUTPUT Bundle (B) Generic Objeto PillBundle estruturado contendo todos os parâmetros empacotados.
OUTPUT JSON (J) Text String JSON serializada pronta para exportar para arquivo ou transmitir entre definições.
OUTPUT Summary (S) Text Resumo detalhado dos parâmetros empacotados.
Pill Bundle Unpack Pills
PillUnpack
Desempacota parâmetros de um PillBundle ou de uma string JSON externa, restaurando as chaves, valores e estruturas de árvore originais com total imutabilidade.
Direção Nome (Sigla) Tipo Descrição
INPUT Bundle (B) Generic Pacote PillBundle ou string JSON contendo os parâmetros estruturados.
INPUT KeyFilter (F) Text Filtro opcional de chaves específicas ou grupos/categorias a extrair (ex: 'ACU', 'GEO', 'MAT', 'ACU_T60'). Se vazio ou '*', desempacota todos os parâmetros contidos.
OUTPUT Keys (K) Text Lista de chaves extraídas.
OUTPUT Values (V) Generic Árvore com os valores desempacotados. O ramo {i} contém os valores da chave K[i].
OUTPUT Summary (S) Text Diagnóstico e resumo do conteúdo desempacotado.

PillCatalog
Varre o documento ativo e o barramento global, catalogando todos os transmitters e receivers. Detecta canais órfãos, transmissões duplicadas, tipos de dados e mapa de dependências.
Direção Nome (Sigla) Tipo Descrição
INPUT Refresh (R) Boolean Pulso opcional para forçar nova auditoria do canvas.
OUTPUT Channels (C) Text Lista com o nome limpo de todos os canais ativos no documento/barramento.
OUTPUT Status (S) Text Status de integridade: 'Conectado (Tx+Rx)', 'Órfão (sem Rx)', 'Órfão (sem Tx)' ou 'Duplicado (Tx Múltiplo)'.
OUTPUT Categories (CAT) Text Categoria de cada canal (ACU, GEO, MAT, SIM, etc.).
OUTPUT Types (T) Text Tipo de dado transmitido em cada canal.
OUTPUT AuditReport (RPT) Text Relatório consolidado de auditoria com estatísticas e integridade de conexões.
Pill Change Detector & Trigger Pills
PillChange
Monitora dados, listas, arvores ou pacotes (PillBundle). Quando detecta qualquer modificacao nos valores, dispara um sinal booleano True (Data Gate / Pulse Trigger) para acionar salvamento de presets, simulacoes ou automacoes.
Direção Nome (Sigla) Tipo Descrição
INPUT Data (D) Generic Dados, listas, arvores ou PillBundle a monitorar continuamente.
INPUT Threshold (T) Number Tolerancia para variacoes numericas (padrao: 0.0001). Variacoes menores que esta tolerancia sao ignoradas.
INPUT Mode (M) Integer Modo de disparo: 0 = Pulso (True apenas no ciclo de alteracao, False quando estavel) 1 = Latch (True enquanto for diferente da referencia inicial) 2 = Toggle (Inverte o booleano a cada mudanca detectada)
INPUT Reset (R) Boolean Pulso para resetar a referencia memorizada para o estado atual.
OUTPUT Changed (C) Boolean Sinal booleano: True se os dados foram modificados nesta solucao (ou conforme o Modo selecionado); False se inalterados.
OUTPUT Pass (D) Generic Pass-through direto dos dados recebidos para encadeamento de fluxo.
OUTPUT Hash (H) Text Assinatura digital (SHA-256) do estado atual dos dados monitorados.
OUTPUT Delta (Δ) Text Diagnostico e resumo da alteracao detectada (delta de contagem, valores e timestamp).
Pill Compute Cache Pills
PillCache
Bypass de recomputacao pesada. Armazena o resultado de operacoes caras (acustica, raytracing, malhas) em memoria associado ao hash dos parametros de entrada. Se as entradas nao mudarem, devolve o cache instantaneamente sem recomputar.
Direção Nome (Sigla) Tipo Descrição
INPUT Key (K) Text Identificador unico da tarefa/calculo em cache. O prefixo define o grupo automaticamente.
INPUT InputParams (P) Generic Parametros ou geometrias de entrada. Se qualquer valor mudar, o cache e invalidado automaticamente.
INPUT ComputedData (D) Generic Resultado pesado da computacao a ser memorizado.
INPUT ForceRecalc (F) Boolean Forca nova computacao e limpa o cache atual desta chave.
INPUT Bypass (BY) Boolean Se True, desativa o cache e sempre passa o dado direto.
OUTPUT Data (D) Generic Dados resgatados do cache ou recem-computados (imutabilidade garantida).
OUTPUT IsCached (C) Boolean True se o resultado foi retornado da memoria cache sem gasto de processamento.
OUTPUT ComputeTime (TS) Text Horario em que o calculo original foi computado.
OUTPUT Stats (S) Text Estatisticas do cache: contagem de hits, hash e diagnostico.

Direção Nome (Sigla) Tipo Descrição
INPUT ParamName (N) Text Nome do parâmetro sob verificação (ex: 'RT60 1000Hz [s]').
INPUT Values (V) Number Valores medidos ou calculados a verificar.
INPUT MinTarget (Min) Number Limite mínimo aceitável.
INPUT MaxTarget (Max) Number Limite máximo aceitável.
INPUT Tolerance (Tol) Number Margem de tolerância opcional (expandindo a faixa aceitável em ±Tol).
OUTPUT Pass (OK) Boolean True se 100% dos valores cumprem os limites de conformidade; False se houver violação.
OUTPUT ComplianceRate (CR) Number Taxa percentual de conformidade [0% a 100%].
OUTPUT Violations (VIO) Text Lista detalhada dos valores em desacordo com as metas.
OUTPUT ConformingValues (CV) Number Subconjunto com os valores aprovados.
OUTPUT Report (RPT) Text Relatório estruturado de conformidade com média e diagnóstico.
Pill Disabler / Kill Switch Pills
PillDisabler
Desativa de verdade (Ctrl+E / Locked) componentes, pilhas ou Pilulas no canvas do Grasshopper. - Zera 100% o consumo de CPU e GPU dos componentes desligados. - Suporta corte direto (Mute) ou alternancia mutua entre Pilha A e Pilha B. - Conexao estilo Galapagos: arraste dos grips ou clique com botao direito para conectar pilhas inteiras. - Cabos com setas e molduras visuais no canvas indicando os componentes controlados.
Direção Nome (Sigla) Tipo Descrição
INPUT Mute / Disable (Mute) Boolean Se True (padrao), desativa a pilha de verdade (Locked = true). Se False, mantem ativada.
INPUT Target Stack (A) (StackA) Generic Componente(s) ou Pilulas da pilha a ser controlada. Puxe conexoes dos componentes ou arraste o conector.
INPUT Stack B (Optional) (StackB) Generic Segunda pilha para alternancia mutua. Se conectada, quando A estiver ativa, B sera desativada, e vice-versa.
INPUT Downstream (Down) Boolean Se True (padrao), tambem desativa todos os componentes conectados a jusante das pilhas controladas.
OUTPUT Status (Status) Text Status atual da execucao das pilhas.
OUTPUT Disabled Count (Count) Integer Quantidade de componentes atualmente desativados de verdade no canvas.
Pill Disk Load Pills
PillLoad
Carrega e restaura com fidelidade total qualquer árvore de dados ou geometria gravada em disco pelo Pill Disk Save (.pilldata ou .ghdata). - Possui busca inteligente de arquivos portátil entre diferentes computadores (resolve automaticamente caminhos de outro PC); - Procura na mesma pasta do arquivo .gh, na subpasta 'PillVault' ou diretório especificado; - Dê duplo-clique no componente para selecionar o arquivo diretamente no disco.
Direção Nome (Sigla) Tipo Descrição

INPUT Directory (DIR) Text Diretório onde procurar o arquivo. Se omitido, procura automaticamente na mesma pasta do arquivo .gh e na subpasta 'PillVault'.
INPUT Reload (R) Boolean Gatilho para forçar a releitura do arquivo do disco (Botão ou Timer).
OUTPUT Data (D) Generic Árvore de dados restaurada com tipos e estrutura originais intactos.

OUTPUT Summary (SUM) Text Informações de diagnóstico do arquivo (itens, galhos, tamanho e caminho em disco).

Pill Domain Filter Pills
PillClip
Filtra e recorta cirurgicamente valores numéricos, listas ou árvores completas (DataTree) com base em um domínio ou intervalo [Min To Max]. - Retorna diretamente os valores numéricos reais aprovados dentro do intervalo (não apenas o ID); - Retorna também os valores descartados (fora do domínio), máscara booleana e índices; - Aceita Interval nativo (ex: '100 To 250') ou limites numéricos individuais (Min / Max); - Modos: 0 = Compactar (remove fora), 1 = Preservar Ramos, 2 = Alinhar com Null (listas paralelas), 3 = Clamp (grampear); - Cápsula Pill integrada com badge [NUM], contadores dinâmicos e transmissão sem fio opcional no PillHub.
Direção Nome (Sigla) Tipo Descrição
INPUT Values (V) Generic Valores numéricos, listas ou árvore completa (DataTree) a inspecionar e filtrar.
INPUT Domain (D) Generic Domínio ou intervalo numérico [Min To Max] (ex: 100 To 250). Opcional se Min e Max forem fornecidos.
INPUT Min (Min) Number Limite inferior aceitável (opcional, sobrescreve ou define o início do domínio).
INPUT Max (Max) Number Limite superior aceitável (opcional, sobrescreve ou define o fim do domínio).
INPUT Inclusive (Inc) Boolean Se True (padrão), inclui os limites borda: Min <= V <= Max. Se False, estritamente aberto: Min < V < Max.
INPUT Mode (M) Integer Modo de saída: 0 = Compactar (remove valores fora e descarta ramos vazios) 1 = Preservar Ramos (mantém ramos vazios estruturais) 2 = Alinhar com Null (substitui descartados por <null> para sincronizar listas paralelas) 3 = Clamp / Grampear (em vez de descartar, ajusta números fora para Min ou Max)
INPUT Key (K) Text Nome opcional do canal Pill para transmissão sem fios automática dos valores filtrados pelo PillHub (categoria [NUM]).
INPUT Active (Active) Boolean Gatilho de ativação do filtro. Se False, opera em pass-through (todos os valores passam em Inside sem cortes).
OUTPUT Inside (In) Number Árvore ou lista contendo os valores numéricos reais que estão DENTRO do domínio escolhido [Min..Max].
OUTPUT Outside (Out) Number Árvore ou lista contendo os valores numéricos descartados (que ficaram FORA do domínio).
OUTPUT Mask (M) Boolean Máscara booleana correspondente aos dados originais (True = Dentro, False = Fora).
OUTPUT Indices (I) Integer Índices originais dos itens que foram aprovados dentro do domínio.
OUTPUT Count (C) Integer Quantidade total de valores aprovados dentro do domínio.
Pill Geometry Filter Pills
PillGeomFilter
Filtro e higienizador de geometrias para simulação acústica e modelagem paramétrica. - Elimina elementos degenerados, micro-faces colapsadas com área próxima de zero, áreas negativas, NaN ou tendendo a -infinity. - Suporta expurgo de micro-triângulos internos em Breps e Malhas compostas. - Preserva a integridade de caminhos GH_Path para árvores de dados a jusante. - Publicação opcional no barramento sem fio PillHub (categoria [GEO]).
Direção Nome (Sigla) Tipo Descrição
INPUT Geometry (G) Geometry Geometrias brutas ou árvores de geometrias a inspecionar e filtrar (Brep, Mesh, Surface, Extrusion, Curve).
INPUT MinArea (Min) Number Área mínima aceitável (m²). Geometrias com área menor ou igual a este limiar, colapsadas, negativas, NaN ou tendendo a -infinito serão sumariamente eliminadas. Default: 0.0001 m² (1 cm²).
INPUT MaxArea (Max) Number Área máxima aceitável opcional (m²). Se definido como valor positivo, geometrias infinitas ou gigantescas que ultrapassarem este limite serão eliminadas. 0 = desativado.
INPUT CleanSubFaces (Sub) Boolean Se True, inspeciona e remove internamente micro-triângulos e faces degeneradas de área zero em Breps e Malhas compostas. Se False, avalia o elemento como um bloco único com máxima velocidade de processamento (Recomendado). Default: False.
INPUT PreservePaths (P) Integer Modo de preservação de caminhos da árvore de dados: 0 = Podar ramos que ficarem vazios 1 = Manter ramos vazios estruturais 2 = Preencher posições eliminadas com <null> (mantém índices de sincronização idênticos)
INPUT Key (K) Text Nome opcional do canal Pill para transmissão sem fios automática das geometrias limpas pelo PillHub (categoria [GEO]).
INPUT Active (Active) Boolean Gatilho de ativação do filtro. Se False, opera em modo pass-through (todas as geometrias passam sem filtragem). O ÚLTIMO PARÂMETRO DA LISTA.
OUTPUT Clean (C) Geometry Árvore contendo apenas as geometrias higienizadas e aprovadas (com área válida > MinArea e livre de degenerações).
OUTPUT Discarded (D) Geometry Árvore contendo as geometrias eliminadas (área próxima a zero, degeneradas, NaN, negativas, infinitas ou inválidas).
OUTPUT Areas (A) Number Árvore com os valores calculados de área (m²) de cada elemento inspecionado.
OUTPUT Pattern (P) Boolean Máscara booleana (True = Aprovada/Limpa, False = Eliminada/Degenerada).
OUTPUT Report (R) Text Relatório estruturado com estatísticas de conformidade, percentual de descarte, menor área detectada e diagnóstico de micro-faces.
Pill Invariant Geometry Pipeline Pills
PillLayers
Pipeline deterministico de geometrias do Rhino imutavel a alteracoes de camadas e indices. - Selecao estavel de camadas pelo FullPath hierarquico (ex: '01_ARQ::PAREDES::CONCRETO'), imune a criacao/exclusao de camadas intermediarias. - Ordenacao canonica estrita (Espacial X->Y->Z, Nome Natural ou GUID) garantindo estabilidade absoluta para Wallacei e Galapagos. - Publicacao automatica no barramento sem fio PillHub e sincronizacao por cabos ocultos.
Direção Nome (Sigla) Tipo Descrição
INPUT LayerFilter (LF) Text Caminho hierarquico completo da camada (ex: '01_ARQ::PAREDES::CONCRETO') ou padrao com wildcard ('*PAREDE*', 'ACU::*'). Se vazio, utiliza a selecao do menu ou da janela visual.
INPUT TypeFilter (TF) Integer Filtro de tipo geometrico: 0 = Qualquer 1 = Brep / Superficie 2 = Malha (Mesh) 3 = Curva 4 = Ponto 5 = SubD 6 = Texto / Anotacao 7 = Extrusao
INPUT SortMode (SM) Integer Criterio de ordenacao canonica: 0 = Espacial 3D (X -> Y -> Z do Bounding Box) [Padrao Wallacei] 1 = Espacial 2D (X -> Y no plano XY) 2 = Nome Natural do Objeto (ex: P1, P2, P10) 3 = Nome do Objeto -> GUID 4 = GUID Estavel
INPUT PillKey (K) Text Chave opcional para publicar automaticamente no barramento sem fio PillHub (ex: '[GEO] Paredes_Auditorio').
INPUT Tolerance (T) Number Tolerancia de comparacao espacial em coordenadas (padrao: 0.001 m).
OUTPUT Geometry (G) Generic Geometrias capturadas e ordenadas deterministicamente.
OUTPUT Names (N) Text Nomes dos objetos no Rhino (ou nome da camada se sem nome).
OUTPUT IDs (ID) Text GUIDs persistentes dos objetos no documento do Rhino.
OUTPUT UserText (TXT) Text Metadados e User Strings dos objetos (chave=valor).
OUTPUT BBoxes (BB) Box Caixas delimitadoras (Bounding Boxes) das geometrias.
OUTPUT Summary (S) Text Diagnostico detalhado: camadas resolvidas, contagem e criterio de ordenacao.
Pill Number Rounder Pills
PillRound
Arredonda valores numéricos individuais, listas ou árvores completas (DataTree) com precisão configurável de casas decimais e modos flexíveis (Nearest, Floor, Ceiling, Truncate). Retorna números nativos e textos formatados.
Direção Nome (Sigla) Tipo Descrição
INPUT Numbers (N) Generic Valores numéricos, listas ou árvores completas (DataTree) a serem arredondados.
INPUT Decimals (D) Integer Quantidade de casas decimais desejada (padrão: 2). Se 0, arredonda para número inteiro.
INPUT Mode (M) Integer Modo de arredondamento: 0 = Mais próximo (Midpoint Away From Zero: 1.25 -> 1.3) 1 = Floor / Para baixo (1.29 -> 1.2) 2 = Ceiling / Para cima (1.21 -> 1.3) 3 = Truncate / Cortar casas (1.29 -> 1.2)

OUTPUT Numbers (N) Number Árvore com os valores numéricos arredondados (tipo double / GH_Number nativo).
OUTPUT Integers (I) Integer Árvore com os valores arredondados para números inteiros (int / GH_Integer).
OUTPUT Text (T) Text Árvore com os valores formatados como texto, mantendo os zeros à direita e o separador configurado.

Pill Preset Vault Pills
PillVault
Cofre de Variantes (Preset Vault) para o ecossistema de Pilulas e Parametros do BURAQUEIRA Tools. - Grava o estado atual de multiplas variaveis, materiais e do Hub em slots de memoria. - Botoes: [ + Gravar Variante ] (com campo de nome) e seletor [<] [Opcao] [>] para carregar e sobrescrever o barramento. - So grava quando clica para adicionar um estado novo (sem gravacao automatica indevida). - Duplo clique: abre o gerenciador de log com os salvamentos; permite excluir linhas selecionadas e impede escrita manual. - Cabos estilo Galapagos conectando o cofre a todos os controles monitorados com moldura [VAULT]. - Salva e persiste todas as variantes no proprio arquivo .gh.
Direção Nome (Sigla) Tipo Descrição
INPUT Hub / Parameters (Hub) Generic Conecte aqui o PillBundle, ou multiplos Sliders, Toggles, Paineis ou Parametros que deseja gravar nas variantes.
INPUT Variant Name (Name) Text Nome para a nova variante a ser gravada (opcional, pode usar o botao [ + Gravar ] no componente).
INPUT Trigger Save (Save) Boolean Pulso (True) para gravar o estado atual como uma nova variante.

Calcula a Divergência de Kullback-Leibler D_KL(P || Q) = Σ P(x) log(P(x)/Q(x)), a Divergência Simétrica de Jensen-Shannon (JSD), a Distância JS e a Entropia Cruzada entre duas distribuições de probabilidade.
Direção Nome (Sigla) Tipo Descrição
INPUT Distribution P (P) Number Distribuição de referência / probabilidade real P(x).
INPUT Distribution Q (Q) Number Distribuição aproximada / modelo simulado Q(x). Deve possuir o mesmo tamanho que P.
INPUT Log Base (Base) Integer Base do logaritmo: 0 = Base 2 (Bits) 1 = Base e (Nats) 2 = Base 10 (Hartleys)
INPUT Epsilon Smoothing (ε) Number Suavização para evitar divisões por zero ou log(0) em probabilidades nulas (padrão: 1e-12).
OUTPUT KL Divergence D_KL(P||Q) (D_KL) Number Divergência de Kullback-Leibler direta D_KL(P || Q) em relação ao modelo Q.
OUTPUT Reverse KL D_KL(Q||P) (D_KL_QP) Number Divergência reversa / assimétrica D_KL(Q || P).
OUTPUT Jensen-Shannon Div (JSD) (JSD) Number Divergência simétrica e limitada de Jensen-Shannon (0.0 a 1.0 em bits).
OUTPUT JS Distance (JSDist) Number Métrica formal de distância entre distribuições (raiz quadrada da JSD).
OUTPUT Cross Entropy H(P,Q) (H_PQ) Number Entropia Cruzada H(P, Q) = H(P) + D_KL(P || Q).
OUTPUT Report (Desc) Text Diagnóstico comparativo e aderência entre as distribuições.
Linear Regression (OLS) Evaluation
LinReg
Executa Regressão Linear Simples por Mínimos Quadrados Ordinários (OLS): - Equação: y = β0 + β1 * x - Coeficiente Angular (Slope β1) = Σ(x - x̄)(y - ȳ) / Σ(x - x̄)² - Coeficiente Linear (Intercept β0) = ȳ - β1 * x̄ - Coeficiente de Determinação R² = 1 - SS_res / SS_tot - Predições ŷ, Resíduos pontuais, Erro Padrão do Slope e Teste t de Significância.
Direção Nome (Sigla) Tipo Descrição
INPUT X Values (X) Number Variável independente / preditora (eixo X).
INPUT Y Values (Y) Number Variável dependente / resposta (eixo Y). Deve possuir o mesmo tamanho que X.
INPUT Eval X (X_eval) Number Valores opcionais de X para avaliação/predição de novos pontos ŷ. Se omitido, avalia sobre o próprio X de entrada.
OUTPUT Slope (β1) (β1) Number Coeficiente angular / inclinação da reta de regressão (taxa de variação de Y por unidade de X).
OUTPUT Intercept (β0) (β0) Number Coeficiente linear / intercepto no eixo Y (valor estimado de Y quando X = 0).
OUTPUT R-Squared (R²) (R²) Number Coeficiente de Determinação R² (proporção da variância de Y explicada por X).
OUTPUT Predicted (Ŷ) (Ŷ) Number Valores preditos ou ajustados pelo modelo linear ŷ = β0 + β1 * x.
OUTPUT Residuals (e) (e) Number Resíduos do ajuste: e_i = y_i - ŷ_i.
OUTPUT Equation (Eq) Text Equação matemática textual da reta ajustada: 'y = a * x + b'.
OUTPUT p-Value (p) Number P-valor do teste t bicaudal para a inclinação β1 (H0: β1 = 0, sem relação linear).
OUTPUT Report (Rep) Text Relatório de diagnóstico detalhado da regressão.

INPUT Loss Type (Type) Generic Função de perda a calcular:
INPUT Parameter (Param) Number Parâmetro adicional da função de perda:
INPUT Weights (W) Number Pesos opcionais por elemento para perda ponderada (ex: importância relativa por banda de oitava ou assento prioritário).
