1. Arquitetura do Barramento Sem Fios (PillHub)

O ecossistema Pills foi desenvolvido para solucionar um dos maiores gargalos de legibilidade no Grasshopper: o "espaguete de fios" que surge quando dezenas de componentes precisam compartilhar parâmetros geométricos, coeficientes de materiais, seleções e gatilhos de simulação.

No coração da arquitetura está o PillHub, um barramento de memória global e reativo por documento que permite aos componentes transmitirem e escutarem dados sem necessidade de fios físicos no Canvas.

1.1 Categorias e Código Cromático Padronizado

Cada canal publicado no barramento possui uma categoria padronizada de 3 letras que define a sua cor visual e facilita a organização no Canvas:

Badge Código Significado / Domínio Exemplos de Parâmetros
GEO GEO Geometria & Espaço Raio, Largura, Comprimento, Número de Assentos, Malhas
ACU ACU Acústica & Áudio RT60, EDT, C80, Faixa de Frequência, Sinal de Áudio
MAT MAT Materiais & Camadas Coeficientes de Absorção, Espalhamento, Densidade, Espessura
SIM SIM Simulação & Cálculo Disparo de Raios, Número de Partículas, Tolerância, Solver
CFG CFG Configurações Globais Modo de Exibição, Diretório de Saída, Unidades, Idioma
OUT OUT Saídas & Resultados Métricas Finais, Relatórios de Conformidade, Listas de Peças
IN IN Entradas Externas Arquivos CSV, Dados Climáticos, Sensores em Tempo Real
VAULT VAULT Cofre de Variantes Snapshots, Presets de Estudo, Alternância de Cenários
CACHE CACHE Cache de Memória Resultados pesados retidos para economia de recálculo

1.2 Convenção de Nomenclatura das Chaves

O PillHub aceita dois formatos universais para chaves de dados:

  • Formato Canônico: [CATEGORIA] NomeDoParametro (ex: [GEO] Raio_Curvatura).
  • Formato Simplificado: CATEGORIA_NomeDoParametro (ex: GEO_Raio_Curvatura).

O sistema é tolerante a variações e automaticamente publica os dois aliases, permitindo pesquisas rápidas por grupo ou por chave individual.

2. Pill Slider Pool (Banco Concentrador de Parâmetros)

O Pill Slider Pool é um painel vertical enriquecido que agrupa sliders, botões, toggles e menus em um único cartão, publicando tudo no PillHub e fornecendo saídas compatíveis com o Gene Pool nativo e o otimizador Galapagos.

2.1 Tipos de Dados Suportados

Badge Tipo Descrição Interação no Canvas
flt Float Número real com casas decimais configuráveis e unidade opcional (ex: 12.5m). Arrastar o manípulo deslizante no trilho.
int Integer Número inteiro discreto (arredondamento passo a passo). Arrasto discreto com passos unitários (1, 2, 3...).
bool Boolean Chave binária True/False para ligar/desligar processos. Clique no Toggle Switch (possui debounce anti-repique de 350ms).
btn Button (Pulse) Botão de pulso momentâneo (Trigger). Clique no botão: emite True no ciclo atual e retorna a False após 80ms.
dom Domain Intervalo numérico (Rhino.Geometry.Interval) com início e fim. Range Slider Duplo: arraste individual do ponto inicial e do final.
list Value List Menu suspenso com opções textuais cadastradas. Clique para abrir o menu flutuante e selecionar a opção desejada.
str String Texto puro editável ou lista de termos. Clique para digitar ou arraste se houver opções.

2.2 Entradas e Saídas (I/O)

Direção Nome (Sigla) Tipo Descrição Detalhada
Input Def (C) List<String> (Opcional) Linhas de configuração textual via Panel. Permite parametrizar e criar toda a pilha dinamicamente via código.
Output Values (V) List<Double> Lista ordenada dos valores numéricos. 100% compatível com Gene Pool e otimização por Galapagos.
Output Keys (K) List<String> Lista com as chaves completas de publicação no PillHub (ex: [GEO] Raio).
Output Tree (T) DataTree<Generic> Árvore de dados estruturada onde cada parâmetro ocupa seu próprio ramo {0}, {1}, preservando seu tipo de dado nativo.

2.3 Sintaxe do Panel / Editor de Texto

Para configurar a pilha, basta conectar um Panel na entrada Def ou dar um duplo-clique no cabeçalho:

# 1. Título do Concentrador
Title = Sala Acústica - Parâmetros

# 2. Slider numérico com limites, unidade e casas decimais
[GEO] Raio = 12.5 (1.0 .. 50.0) [m] [float]

# 3. Inteiro discreto
[GEO] Assentos = 120 (10 .. 500) [int]

# 4. Toggle booleano com proteção de Auto-Reset [r]
[SIM] Ativar_Calculo = False [bool] [r]

# 5. Botão de Disparo / Pulso Momentâneo (Trigger)
[SIM] Disparar_Raios [btn]

# 6. Domínio / Faixa com dois limites
[ACU] Banda_Oitava = 250 .. 4000 (100 .. 8000) [Hz] [dom]

# 7. Menu suspenso (Value List / Dropdown)
[MAT] Tipo_Painel = Madeira ("Madeira", "Vidro", "Gesso", "Cortiça") [list]
O Modificador de Segurança [r] (Auto-Reset ao Abrir):
Similar ao FalseStartToggle do Ladybug Tools, colocar a tag [r] faz com que o parâmetro retorne automaticamente ao seu valor padrão seguro toda vez que o arquivo .gh for aberto. Isso impede que arquivos com cálculos pesados travem o computador imediatamente na abertura.

3. Pill Preset Vault (Cofre de Variantes & Estudos)

O Pill Preset Vault é o componente definitivo para comparar opções de projeto. Ele captura e restaura com um único clique o estado de múltiplos parâmetros, componentes ou até mesmo de pilhas inteiras (como coeficientes de absorção de materiais).

3.1 Identidade Visual Estilo "Pill"

O componente foi projetado na linguagem estética da família Pill:

  • Cápsula Escura Arredondada: Fundo gradiente profissional (#1c2026 a #14181c) com borda curva violeta (#9333ea).
  • Badge Interno [VAULT]: Retângulo com cantos arredondados na cor do tema.
  • LED Luminoso de Status: 🟢 Verde Esmeralda (quando há variantes salvas e ativas) ou 🟡 Âmbar (quando vazio).
  • Navegação Vetorial: Setas ◀ e ▶ desenhadas em vetor geométrico anti-aliased (livre de glitches de fonte) para alternar opções.
  • Barra Superior: Botões modernos [+ NOVA] (azul) e [SALVAR] (âmbar) para operação instantânea.

3.2 Conexão Estilo Galapagos (Wire Linker)

Como Conectar Pilhas Inteiras ou Sliders ao Cofre:
Você não precisa puxar fios comuns na saída de dados! Basta clicar no Grip (conector redondo) de entrada Hub / Parameters e arrastar o mouse até o componente desejado (ex: Pill Slider Pool, Material Stack, Sliders avulsos). Uma linha estilizada com moldura [VAULT] conectará os componentes. Para desconectar, segure Ctrl e arraste novamente sobre o componente.

3.3 Funcionalidade de Gravação e Sobrescrita

Ação Como Acionar Comportamento Realizado
Gravar Nova Variante Botão [+ NOVA] Abre diálogo para digitar o nome da nova variante e grava o estado de todos os controles monitorados.
Sobrescrever Atual Botão [SALVAR] Com apenas 1 clique, atualiza os valores da variante selecionada no momento com as posições atuais do Canvas.
Navegar entre Estudos Setas ◀ e ▶ Aplica os valores da variante anterior/próxima diretamente nos sliders e componentes do Grasshopper.
Gerenciador de Log Duplo-clique no componente Abre tabela completa de auditoria com data/hora, resumo dos valores, botão de excluir e botão [Sobrescrever Selecionada].

3.4 Persistência Confiável no Arquivo .gh

O componente implementa persistência dupla:

  1. Notificação ao Grasshopper: Ao gravar, sobrescrever ou excluir uma variante, o componente aciona RecordUndoEvent() e doc.Modified(), garantindo que o Grasshopper marque o arquivo como modificado e salve as alterações ao pressionar Ctrl+S ou fechar o Rhino.
  2. Payload Seguro Duplo: Os dados são gravados tanto na árvore de nós nativa do Grasshopper (Chunks) quanto em uma estrutura JSON completa (VaultJson). Caso algum nó sofra corrupção, o payload JSON restaura 100% dos dados.

4. Pill Transmitter & Pill Receiver (Transmissão Sem Fios)

O par Transmitter / Receiver é a base do tráfego de dados ponto-a-ponto e ponto-multiponto no barramento PillHub.

4.1 Pill Transmitter (Publicador)

  • Função: Publica qualquer dado (números, geometrias, materiais, sinais de áudio, árvores completas) em um canal nomeado.
  • Entradas:
    • Data (D): Dado a ser transmitido (item ou árvore).
    • Key (K): Chave de publicação (ex: [GEO] Raio ou GEO_Raio).
    • Unit (U): Unidade opcional (ex: m, s, dB).
  • Visual: Cápsula ultra compacta com badge na cor da categoria e indicador LED ativo.

4.2 Pill Receiver (Receptor)

  • Função: Escuta o barramento PillHub e fornece os dados imediatamente na sua saída, sem fios.
  • Modos de Escuta:
    • Chave Exata: Escuta apenas aquele canal específico (ex: [GEO] Raio).
    • Grupo Inteiro: Se configurado para uma categoria (ex: ACU ou [ACU]), ele extrai e combina todos os dados dessa categoria.
    • Wildcard Global (* ou ALL): Recebe todos os canais cadastrados no arquivo.
  • Saídas:
    • Data (D): Os dados restaurados mantendo a árvore original.
    • Info (I): Metadados do canal (unidade, última atualização, transmissor).

5. Pill Bundle Pack & Unpack (Pacotes Estruturados)

Quando múltiplos dados precisam viajar juntos como uma única unidade conceitual (por exemplo: um Material Acústico composto por Nome, Curva de Absorção de 6 bandas, Espalhamento e Cor), utiliza-se o Pill Bundle.

5.1 Funcionamento

  • Pill Bundle Pack: Recebe múltiplos nomes e valores e cria um pacote único imutável tipado.
  • Pill Bundle Unpack: Recebe o pacote e extrai cada campo diretamente por chave ou índice.
  • Compatibilidade: O Pill Preset Vault é capaz de identificar PillBundles automaticamente e salvá-los integralmente no cofre de variantes.

6. Pill Compute Cache (Cache Inteligente de Simulação)

Simulações acústicas (como traçado de raios no Pachyderm, simulação de Schroeder ou solvers estruturais) exigem alto consumo de CPU. O Pill Compute Cache atua como um escudo protetor para evitar recálculos desnecessários.

6.1 Sistema de Fingerprint Profundo (Deep Fingerprint)

Diferente de caches comuns que apenas comparam referências em memória, o Pill Cache calcula um hash criptográfico profundo (SHA256) dos dados de entrada:

  • Se você alterar um slider que não está conectado na simulação, o cache não recalcula e entrega o resultado anterior instantaneamente.
  • Ele analisa profundamente coeficientes de absorção de materiais, listas de sinais de áudio e geometrias. Se nada mudou, economiza preciosos minutos de processamento.
  • Possui botão manual [LIMPAR CACHE] e entrada booleana Force para recalcular sob demanda.

7. Pill Disabler (Desabilitador Condicional de Pilhas)

Permite ligar e desligar componentes e grupos inteiros do Canvas com base em uma condição booleana, utilizando o mesmo cabo inteligente estilo Galapagos.

  • Conecte o Pill Disabler a qualquer conjunto de componentes pesados.
  • Quando a entrada booleana for False, os componentes são colocados no estado Disabled (cinza), liberando 100% da memória e CPU do Grasshopper.

8. Pilhas Utilitárias

8.1 Pill Change Detector

Monitora um fluxo de dados e emite um pulso de True apenas quando os dados mudarem de fato. Ideal para disparar salvamentos automáticos ou notificações sonoras.

8.2 Pill Constraint Checker

Verifica se um valor acústico ou geométrico está dentro dos limites da norma (ex: $RT_{60} \le 1.2\text{ s}$). Exibe bordas coloridas no componente (Verde para Aprovado, Vermelho para Reprovado) e emite relatórios automáticos de conformidade.

8.3 Pill Catalog

Painel de controle geral. Coloque no Canvas para ver em tempo real uma tabela com todos os transmissores, canais, valores e receptores conectados em todo o documento.

9. Guia de Manutenção e Atualização Deste Manual

Este manual foi projetado com uma arquitetura de documentação viva (Living Documentation). Sempre que novas funcionalidades, novos parâmetros ou novas pilhas forem adicionados ao Buraqueira Tools, o PDF pode ser atualizado de forma 100% automatizada.

9.1 Como Regenerar o PDF Atualizado

Existe um script de automação pronto em PowerShell que lê o código-fonte deste documento e utiliza o motor do Microsoft Edge / Google Chrome em modo headless para compilar o PDF com renderização tipográfica perfeita:

# Executar no PowerShell para atualizar o manual em PDF:
powershell -ExecutionPolicy Bypass -File "g:\Meu Drive\PROJETOS\Teatro escola\pachyderm\Buraqueira_Tools\generate_manual_pdf.ps1"

9.2 Estrutura de Arquivos da Documentação

  • Buraqueira_Tools_Manual_Pills.html: Arquivo fonte mestre em HTML5 com estilização para impressão A4.
  • generate_manual_pdf.ps1: Script gerador que produz o arquivo Buraqueira_Tools_Manual_Pills.pdf.
